# 测试点提取指南

> 本文件为生成测试用例时的速查表。LLM 在为每个故事提取测试点时，按照故事涉及的「页面类型」与「机制类型」查表，避免遗漏常规测试点。
>
> 本指南**只列出常规测试点**，PRD 中明确写出的特殊规则仍需单独提取。
> 本指南**不替代** PRD —— 表里列出的测试点，如果 PRD 没有提供对应的字段/按钮/规则信息，不要凭空生成用例。

---

## 一、按页面类型查测试点

PRD 17 类标准页面类型对应的常规测试点。

### ① 工作台

| 测试项 | 测试点 |
| --- | --- |
| 核心流程 | 不同角色登录后工作台展示内容差异 |
| 关键分支 | 待办点击 → 跳转到对应单据；快捷入口跳转准确 |
| 权限校验 | 无对应角色看不到对应卡片/区域 |
| 异常边界 | 待办为空时的兜底展示；统计数据为 0 的展示 |

### ② 表格列表

| 测试项 | 测试点 |
| --- | --- |
| 核心流程 | 列表正常加载 + 默认排序 + 默认筛选生效 |
| 关键分支 | 搜索、筛选、分页、排序各自生效；行操作按钮触发对应页面 |
| 权限校验 | 行级数据可见性（只能看到本人/本部门）；按钮显隐符合角色 |
| 字段校验 | 搜索关键字格式校验（如有） |
| 异常边界 | 列表为空时的兜底；超大数据量分页 |

### ③ 表单页面（部署流程机制）

| 测试项 | 测试点 |
| --- | --- |
| 核心流程 | 新建 → 暂存 → 提交 → 审批通过 全链路 |
| 关键分支 | 审批驳回 → 重新提交；撤回；转办；审批多节点 |
| 权限校验 | 起草人/审批人按钮显隐差异；审批中只读 |
| 字段校验 | 必填字段、字段格式、字段长度、唯一性 |
| 异常边界 | 重复提交、并发编辑、附件超限、流程配置缺失 |
| 状态流转 | 草稿 → 审批中 → 已通过 / 已驳回 / 已撤回 |

### ④ 表单页面（没有部署流程）

| 测试项 | 测试点 |
| --- | --- |
| 核心流程 | 新建 → 保存 → 列表出现 |
| 关键分支 | 编辑修改保存；删除 |
| 权限校验 | 仅创建人/管理员可编辑/删除 |
| 字段校验 | 必填、格式、唯一性 |
| 异常边界 | 重复保存、并发编辑 |

### ⑤ 看板视图 / ⑥ 卡片视图

| 测试项 | 测试点 |
| --- | --- |
| 核心流程 | 卡片正确分组展示；点击进入详情 |
| 关键分支 | 拖拽变更状态（如支持） |
| 权限校验 | 只能拖拽自己有权限的卡片 |

### ⑦ 甘特图 / ⑧ 日历视图 / ⑩ 资源视图

| 测试项 | 测试点 |
| --- | --- |
| 核心流程 | 时间轴正确加载；事件正确落位 |
| 关键分支 | 切换时间粒度（日/周/月）；拖拽改时间（如支持） |
| 异常边界 | 时段冲突提示；跨天/跨月边界 |

### ⑨ 统计报表

| 测试项 | 测试点 |
| --- | --- |
| 核心流程 | 指标按筛选条件正确聚合 |
| 关键分支 | 切换维度/时间范围/钻取 |
| 异常边界 | 数据为空时的兜底；超大时间范围加载 |

### ⑪ 弹窗表单 / ⑫ 抽屉表单

| 测试项 | 测试点 |
| --- | --- |
| 核心流程 | 打开 → 填写 → 确定 → 关闭 → 数据落库 |
| 关键分支 | 取消 → 数据不落库；关闭后再次打开数据不残留 |
| 字段校验 | 必填、格式 |
| 异常边界 | 重复确定（防抖）；ESC 关闭行为 |

### ⑬ 配置项表单

| 测试项 | 测试点 |
| --- | --- |
| 核心流程 | 修改 → 保存 → 业务侧立即生效 |
| 权限校验 | 仅管理员可修改 |
| 字段校验 | 格式、范围 |
| 异常边界 | 保存失败回滚；并发修改 |

### ⑭ 分类管理（标准分类模型）

| 测试项 | 测试点 |
| --- | --- |
| 核心流程 | 新增分类 → 树正确展示 → 在分类下新建文档 |
| 关键分支 | 编辑分类、删除分类（带数据时拦截） |
| 权限校验 | 分类管理权限校验 |

### ⑮ 模版管理（分类模版模型）

| 测试项 | 测试点 |
| --- | --- |
| 核心流程 | 分类 → 模版 → 基于模版新建业务单据 |
| 关键分支 | 模版编辑/停用；停用后不能新建 |
| 权限校验 | 模版管理权限 |

### ⑯ 模板配置页（设计态机制）

| 测试项 | 测试点 |
| --- | --- |
| 核心流程 | 字段拖入 → 保存 → 业务侧生效 |
| 关键分支 | 字段排序、字段属性修改、字段删除 |
| 权限校验 | 仅模版管理员可配置 |

### ⑰ 后台表单扩展配置页（配置态机制）

| 测试项 | 测试点 |
| --- | --- |
| 核心流程 | 配置某机制 → 保存 → 对应业务能力生效 |
| 关键分支 | 关闭机制 → 对应能力不可见 |
| 权限校验 | 仅后台管理员可配置 |

## 二、按平台机制查测试点

PRD 中通过"部署 XX 机制"声明的能力，对应的常规测试点。

### 流程引擎机制

| 测试项 | 测试点 |
| --- | --- |
| 核心流程 | 提交 → 节点1 → 节点2 → 完成 |
| 关键分支 | 驳回到指定节点；撤回；转办；加签；并签 |
| 权限校验 | 仅当前节点处理人可操作；其他人只能查看 |
| 异常边界 | 流程未配置时提交失败；处理人离职时的兜底 |
| 状态流转 | 全部合法状态间的流转 |

### 权限引擎机制

| 测试项 | 测试点 |
| --- | --- |
| 权限校验 | 角色权限点生效；按钮显隐；行级数据可见性 |
| 异常边界 | 越权访问 URL 被拦截；权限变更后实时生效 |

### 编号机制

| 测试项 | 测试点 |
| --- | --- |
| 核心流程 | 提交时自动生成编号 |
| 字段校验 | 编号格式符合配置；编号全局唯一 |
| 异常边界 | 并发提交编号不冲突；跨年/跨月编号规则切换 |

### 消息/通知机制

| 测试项 | 测试点 |
| --- | --- |
| 核心流程 | 触发条件满足 → 指定接收人收到通知 |
| 关键分支 | 阅读状态切换；按消息跳转到对应单据 |
| 异常边界 | 接收人列表为空；消息发送失败的兜底 |

### 传阅机制

| 测试项 | 测试点 |
| --- | --- |
| 核心流程 | 单据完成 → 自动传阅给指定人 |
| 关键分支 | 阅读 / 未读状态切换；批量阅 |
| 权限校验 | 传阅人范围内的人才能看到 |

### 表单引擎机制

| 测试项 | 测试点 |
| --- | --- |
| 核心流程 | 表单设计 → 保存 → 业务侧渲染一致 |
| 关键分支 | 字段属性变更（必填/只读/隐藏）业务侧生效 |
| 异常边界 | 已有数据时字段类型变更的兼容 |

### 分类模板机制

| 测试项 | 测试点 |
| --- | --- |
| 核心流程 | 选分类 → 选模版 → 加载对应表单/流程 |
| 关键分支 | 模版停用后不可见；切换模版时表单切换 |

### 列表机制 / 资源视图机制（含资源日历）

| 测试项 | 测试点 |
| --- | --- |
| 核心流程 | 视图正确渲染；资源占用正确显示 |
| 关键分支 | 切换视图；筛选资源 |
| 异常边界 | 资源冲突提示；时段重叠拦截 |

### ES 日志机制

| 测试项 | 测试点 |
| --- | --- |
| 核心流程 | 关键操作产生日志记录 |
| 异常边界 | 日志查询的分页和过滤 |

## 三、按数据类型查校验测试点

### 文本字段

- 必填校验
- 最大长度
- 特殊字符（含 emoji、SQL 注入预防、HTML 转义）
- 前后空格处理

### 数值字段

- 必填、格式（整数/小数）
- 最小值 / 最大值
- 负数处理
- 精度（小数位）

### 日期/时间字段

- 必填、格式
- 起止时间约束（开始 ≤ 结束）
- 跨天/跨月/跨年边界
- 时区（如有跨时区场景）

### 组织架构字段（人员/部门）

- 必填
- 离职人员的兜底显示
- 部门变更后历史数据保留原值

### 附件字段

- 必填
- 单个文件大小上限
- 文件类型白名单/黑名单
- 文件数量上限

### 唯一性字段

- 同模块内唯一
- 编辑保存自身不冲突
- 并发新建的冲突拦截

## 四、使用顺序

为每个用户故事提取测试点时，按以下顺序：

1. **看故事涉及的页面**，在「按页面类型查」中找通用测试点
2. **看实体部署的机制**，在「按平台机制查」中补充机制相关测试点
3. **看故事的字段表**，按字段类型在「按数据类型查」中找校验测试点
4. **读故事底部"全局业务规则限制"**，把每条规则转为对应测试用例（通常归入"异常边界"或"状态流转"）
5. **去重**，多个来源指向同一测试点的合并

最终用例数控制在每故事 3-8 条（核心覆盖版）。如果按上述穷举出超过 8 条，按优先级保留：核心流程 > 关键分支 > 异常边界 > 字段校验 ≈ 权限校验 > 状态流转（局部）。
